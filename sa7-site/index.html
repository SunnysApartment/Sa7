How it works

  1. Type as usual, even when the keyboard is in the wrong language.
  2. Select the text. Nothing selected? Sa7 fixes the last word you typed.
  3. Press ⌃ K. Not what you wanted? Press it again right away to undo.

What it does, and what it doesn't

Fixes

  • Does: Works in any app you can type in that supports copy and paste.
  • Does: Figures out the direction by itself, then switches your keyboard to the right language.
  • Does: In mixed text, fixes only the wrong words, using your Mac's dictionary.
  • Does: Turns Franco into Arabic: ezayak 3amel eh becomes ازيك عامل ايه.
  • Does: Knows Arabic, Persian and Urdu keyboards, with English or French AZERTY.

Stays out of your way

  • Does: Shows the fix in a small bubble next to your text, with a soft sound if you like.
  • Does: Leaves the words on your never-flip list alone, like names and brands.
  • Does: Turns off in the apps you choose, like games or Terminal, so ⌃ K works there as usual.
  • Does: Puts back whatever you had copied, and stays out of clipboard-history apps.

Extras, when you want them

  • Does: Fixes copied text with Fix clipboard in the menu, for apps that don't let you select text.
  • Does: Can point out a word typed in the wrong keyboard as you type, if you turn it on. You press ⌃ K to fix it.
  • Does: Keeps all its options in one Settings window, in English or Arabic.
  • Does: Never goes online, unless you turn on the update check.
  • Does: Free and open source under the MIT license.

What it doesn't do yet

  • Doesn't: When the dictionary doesn't know a word, like dialect or slang, it flips the whole selection. Select just the wrong part then.
  • Doesn't: There's no Windows app yet. On Windows and Chromebooks, use the Chrome extension.

Install

Two ways. The Terminal one skips the warning macOS shows for apps that aren't notarized by Apple yet.

Fastest: one Terminal command

Open Terminal, paste this and press Return. It puts Sa7 in Applications and opens it.

curl -fsSL https://sunnysapartment.github.io/Sa7/install.sh | bash

Then turn Sa7 on under Accessibility when its window asks. Run the same command any time to update.

Or use the download

  1. Open the downloaded Sa7.dmg and drag Sa7 to Applications.
  2. Open Sa7 from Applications. macOS says it can't verify the developer.
  3. Go to System Settings, then Privacy & Security, scroll down and click Open Anyway.
  4. The Sa7 window appears. Click Open Settings and turn Sa7 on under Accessibility. The window updates by itself, no restart needed.

No Open Anyway button? Run this in Terminal, then open Sa7 again: xattr -cr /Applications/Sa7.app

You need an English keyboard (ABC, US or French AZERTY) and an Arabic, Persian or Urdu keyboard. Add them in System Settings, under Keyboard, then Text Input.

More ways to use Sa7

In Chrome, on any computer

The Chrome extension does the same fixing in any text box in the browser, on Windows and Chromebooks too. It isn't in the Chrome Web Store yet, so you add it from a zip for now.

  1. Download Sa7-chrome.zip and unzip it.
  2. Open this address in Chrome and turn on Developer mode, top right.
    chrome://extensions
  3. Click Load unpacked and pick the unzipped folder.

With Homebrew

Already use Homebrew on your Mac? This installs Sa7, and brew upgrade keeps it up to date.

brew install --cask sunnysapartment/sa7/sa7

Questions

Is it free?

Yes, and open source under the MIT license. All the code is on GitHub.

Does it send what I type anywhere?

No. Sa7 never connects to the internet, unless you turn on the update check in Settings, and then it only looks for a newer version. The only thing it saves is its own settings, like your shortcut and your never-flip list, on your Mac.

Why does it need Accessibility permission?

To copy the selected text and paste the fix in its place, the same way you would by hand.

I installed a new version and the shortcut stopped working.

From version 1.1.1 on, updates keep the permission. Coming from an older version, macOS may show Sa7 as switched on while it no longer applies, and switching it off and on doesn't help. Open the Sa7 setup window from the menu and click Reset permission (version 1.2.1 or later), or run this in Terminal, then turn Sa7 on again when it asks: tccutil reset Accessibility com.khaledomar.sa7

Does the typing hint read everything I type?

No. It's off unless you turn it on, in Settings under Typing. When it's on, Sa7 looks only at the word you're typing right now, in memory, and stores nothing. It never changes your text by itself: it shows a small hint, and you press ⌃ K if you want the fix. macOS may ask you to allow Input Monitoring for it.

Can I use it in Chrome on Windows?

Yes, with the Chrome extension. It fixes text in any text box in Chrome, on Windows, Chromebooks and Macs. There's no Windows app yet.
